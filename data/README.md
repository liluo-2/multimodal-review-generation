# Data

## Source

[Amazon Reviews 2023](https://amazon-reviews-2023.github.io/) (McAuley Lab, UCSD).

We use three categories: **Arts_Crafts_and_Sewing**, **Sports_and_Outdoors**, **Toys_and_Games**.

## Expected structure

```
data/
├── Arts/
│   ├── final.jsonl                          # preprocessed samples (history + reference)
│   └── img2txt/
│       ├── train_all_hist_both_img2txt.jsonl
│       ├── train_all_hist_img_only_img2txt.jsonl
│       ├── test_all_hist_both_img2txt.jsonl
│       └── test_all_hist_img_only_img2txt.jsonl
├── Sports/
│   └── ...
├── Toys/
│   └── ...
└── splits/
    ├── Arts_both_split.npz
    ├── Arts_img-only_split.npz
    ├── Arts_text-only_split.npz
    ├── Sports_both_split.npz
    └── ...
```

### `final.jsonl`

Each line is a JSON object:
```json
{
  "history": [
    {
      "product_title": "...",
      "text": "user review text",
      "rating": 4.0,
      "description": "product description or null",
      "parent_asin": "B00XXXX"
    }
  ],
  "reference": {
    "text": "ground truth review",
    "rating": 3.0,
    "product_title": "...",
    "description": "...",
    "parent_asin": "B00YYYY"
  }
}
```

### Split files (`.npz`)

Each `.npz` contains arrays `train_random` and `test_random`, holding integer indices into `final.jsonl`.

### Image descriptions

Generated by `inference/img2txt.py` using Qwen2.5-VL. Each line:
```json
{
  "id": "42",
  "image_descriptions": [
    {"image": "B00YYYY.jpg", "description": "A set of colorful craft beads..."}
  ]
}
```

## Data paths in code

The GRPO training script (`training/grpo/train_grpo.py`) expects:

| Argument | Points to |
|---|---|
| `--dataset_path` | `data/{Dataset}/final.jsonl` |
| `--split_path` | `data/splits/{Dataset}_{modality}_split.npz` |
| `--image_desc_paths` | comma-separated paths to `img2txt` jsonl files |
| `--hist_img_desc_path` | path to history item image descriptions |

See `configs/paths.yaml` for a template.
